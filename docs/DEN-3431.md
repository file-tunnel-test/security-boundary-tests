# DEN-3431 — encrypted-object integrity and interrupted-transfer safety

This independent test-organization contract preserves the current production
resume primitive instead of treating it as encrypted-object certification. The
pinned File Tunnel source already rejects gaps, overlaps, changed totals,
conflicting replays, and unbounded declared sizes while making exact matching
retries idempotent. It does **not** currently expose a complete AES-GCM, KMS key
version, verified object checksum, retention cleanup, and tenant-scoped
decryption adapter.

The hermetic reference model therefore certifies the required security contract
without importing production code:

- pure-reference AES-256-GCM checked against a NIST vector;
- 96-bit nonces derived from tenant, object, upload-generation/session ID, KMS key version, and chunk index, preventing nonce reuse when an object coordinate is reused;
- authenticated additional data binding tenant, object, key version, chunk
  index, byte offset, total size, and plaintext checksum;
- whole-file SHA-256 for small objects and per-chunk SHA-256 manifests for large objects, with large-object finalization verifying one plaintext chunk at a time instead of reconstructing the whole object;
- strict contiguous resume, idempotent exact replay, conflicting replay and gap
  rejection, bounded object/chunk counts, and zero retained plaintext staging
  after each commit;
- uniform failure for tag, ciphertext, AAD, manifest, checksum, tenant, missing/wrong KMS version, wrong key material, and upload-session binding failures;
- deterministic mixed-state retention cleanup with legal-hold protection;
- a hash-chained audit ledger carrying initiator, tenant/object target, bytes,
  checksum, KMS key version, final status, and timestamp without key or object
  material;
- deterministic retained evidence.

The evidence deliberately records `liveEncryptedObjectAdapterCertified=false`.
A live certification claim requires the production adapter listed in the source
pin to exist and to pass this same corpus at an immutable source head.
